# Parser Output Directory

This directory contains FHIR data extracted and organized into two parallel schemas:

## Directory Structure

```
parser_output/
├── fhir_analysis/      # Full FHIR metadata with validation, lineage, timestamps
└── npd_compliant/      # Minimal NPD-compliant schema for database import
```

## Quick Start

### For Analysis & Debugging
Use files in `fhir_analysis/`:
- Has complete metadata, validation results, and data lineage
- Used by Step52 (endpoint discovery)
- Contains `endpoint_to_npi.csv` with NPI validation status

### For Database Import
Use files in `npd_compliant/`:
- Minimal schema matching NPD specification
- Stripped `npd_` prefixes for cleaner names
- Ready for PostgreSQL COPY commands

## Key Files

| Purpose | FHIR Analysis | NPD Compliant |
|---------|---------------|---------------|
| Endpoints | `fhir_analysis/endpoint_instance.csv` | `npd_compliant/endpoint_instance.csv` |
| NPIs | `fhir_analysis/endpoint_to_npi.csv` | `npd_compliant/endpoint_to_npi.csv` |
| Organizations | `fhir_analysis/organization.csv` | `npd_compliant/organization.csv` |

## Important Notes

✅ **Both schemas share the same UUIDs** - You can join data between them using the `id` column

✅ **File renamed for clarity** - `endpoint_instance_to_other_id.csv` → `endpoint_to_npi.csv`

✅ **Prefixes stripped in NPD directory** - `npd_endpoint_instance.csv` → `endpoint_instance.csv` (in npd_compliant/)
