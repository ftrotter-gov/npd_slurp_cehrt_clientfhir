The purpose of this project
======

 is to download the list of Electronic Health Record (EHR) vendors from the Lantern project. That vendor list includes links to each EHR vendor’s client list.

For each EHR vendor, the project will:

* Download the vendor’s client list.
* Verify that the client list is accessible and functioning correctly.
* Analyze the client list to determine whether it complies with the applicable standards.
* Generate a report summarizing the compliance status, accessibility, and any issues identified for each vendor.
